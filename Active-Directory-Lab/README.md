# Active Directory Home Lab
## Overview
This lab demonstrates hand on experience with Windows Server and Active Directory in a virtualized environment.
## Objectives
-Install and configure Windows Server
-Install Active Directory Domain Services (AD DS)
Create and configure a domain
Create users and security group
Configure DNS
Join a windows client computer to the domain
Configure and test Group Policy
Troubleshoot common Active Directory issues
## Technologies Used
- Window Server
- Windows 10/11
- Active Directory Domain Services
- DNS
- Group Policy
- Virtualbox
